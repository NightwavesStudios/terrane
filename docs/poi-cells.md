# Where the POI cells live

The world harvest is **370 MB across 1,869 files** — 1,007 cells and 862 parking
files — covering **9,371,124 places from 437 OpenStreetMap country extracts**
(harvested 2026-11-18). That is more than a git clone should carry and far more than
a static build wants to copy, so the cells are **not in this repository**. They are
uploaded to object storage and read from there.

## The store

`poi-bucket/worker.js` is a small Worker in front of an R2 bucket.

| | |
| --- | --- |
| Read | `GET /poi/6/33/22.json` → `content-type: application/json`, `cache-control: public, max-age=86400`, `access-control-allow-origin: *` |
| Write | `PUT /upload/poi/6/33/22.json` with header `x-upload-token`, compared against the `UPLOAD_TOKEN` site secret |
| Missing | a plain `404`, which the loader already treats as "not harvested yet" |
| Address | `https://terrane-poi-cells-mqa53q-preview.freebuff.site` |

Nothing outside the token can write to it, so the bucket cannot be poisoned by a
third party. The map reads it exactly as it read `public/poi`, because the path is
the same.

## The loader

`src/map/poi.ts` builds every request from one constant:

```ts
const POI_BASE = (import.meta.env.VITE_POI_BASE ?? "https://terrane-poi-cells-…").replace(/\/+$/, "");
```

Set `VITE_POI_BASE` to point a build at a different bucket, a fork's copy, or a
local mirror served from `public/poi`. Nothing else in the client knows where the
cells come from.

## Refreshing it

```bash
npm run poi:world                 # download + parse Geofabrik extracts (resumable)
npm run poi:merge                 # dedupe, tile, validate, swap public/poi
npm run poi:report && npm run poi:stats
POI_BUCKET=https://terrane-poi-cells-mqa53q-preview.freebuff.site \
  POI_UPLOAD_TOKEN=… npm run poi:push
```

`poi:push` walks `public/poi`, PUTs each file six at a time and prints the ones that
failed, so a partial upload is visible rather than silent. Re-uploading a cell
replaces it; the loader's 24-hour cache header means a browser may hold the old one
until it expires.

## What the numbers in the UI mean

`src/data/poi-stats.json` is generated by `npm run poi:stats` from
`reports/poi-coverage.json`, which the merge writes. The globe footer and the World
POIs switch both read it, so the figure on the page is the figure the merge
produced — 9,371,124 places, 1,869 files, 437 extracts — and cannot drift away from
the cells being served.

`public/poi/` is gitignored. A fresh clone has no cells until the harvest runs or the
bucket is mirrored locally, but the app builds without them; it simply shows no pins.
